- A service that builds and names a `platform:` is now built for that platform: `container build` is given `--platform` as `container run` already was. The image was built for the host's arm64 and then run as `linux/amd64` under Rosetta, so a Dockerfile that needs amd64-only packages failed to build where docker compose builds it. An image built before this change is not rebuilt on its own: run `opossum up --build` (or `opossum build`) once for such a service. Its `RUN` steps now go through Rosetta, so the build may take longer than before.
