> [!WARNING]
> **Some compose files that loaded before are now refused, and some commands now ask for the profile you started with.**
>
> A string that docker compose cannot cast is refused when the file is read, as docker compose refuses it: `cpu_shares: "abc"`, `cpu_shares: "0x10"`, `pids_limit: "100.0"` and `privileged: "maybe"` no longer load. Write a plain decimal integer (`"100"`) or a boolean word (`"yes"`). A project already running on such a file is refused by `down` too: take it down by its name, `opossum -p <name> down`.
>
> A service that depends on a service behind a profile is now checked by `ps`, `logs` and the other commands that read the project, and by `stop` and `kill` when you name it, as `up` already checked it. A project started with `--profile <name>` needs the same `--profile` for those commands. `down`, and `stop` with no service named, go on without it.

> [!WARNING]
> **`down --rmi local` now removes an image built under your own `image:` name.**
>
> A service with both `build:` and `image: myapp:1` loses `myapp:1` on `down --rmi local` when this version built it. It used to be left. An image an earlier version built, or one you built yourself under that name, is left. If you keep that image to push or reuse, run `down` without `--rmi`.
