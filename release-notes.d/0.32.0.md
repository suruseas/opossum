> [!WARNING]
> **Services behind a profile are now read as docker compose reads them, so `up`, `pull` and `build` can do something different with a file that worked with v0.31.0.**
>
> **`up` refuses a file for a service it was not asked to start.** If any service depends on a service behind a profile that is not active, `opossum up web` now refuses the file and names that service, as docker compose does, where it used to start `web`. Fix what the message names, or turn the profile on, as in `opossum --profile debug up web`.
>
> **`pull` and `build` leave out a service behind a profile that is not active.** A script that runs `opossum pull` or `opossum build` to have every image ready now gets only those of the services the active profiles enable. Add `--profile <name>` or set `COMPOSE_PROFILES` for the rest; every command now takes `--profile`.
