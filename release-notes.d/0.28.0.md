> [!WARNING]
> **`opossum run` and `opossum exec` now exit with the command's own exit code.**
> They used to exit with `1` for every failure. A script that treats any non-zero
> exit as failure is unaffected; one that checks for exactly `1` should check for
> non-zero instead. A failure of opossum itself before the command runs still
> exits `1`. The entry below has the details, including `run --audit`.
