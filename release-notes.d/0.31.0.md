> [!WARNING]
> **Two changes can break a script or a setup that worked with v0.30.0.**
>
> **`opossum logs` now puts the service in front of every line** (`web-1  | hello`), for one service as for several, as docker compose does. A script that reads `opossum logs web` line by line gets the prefix after this upgrade: add `--no-log-prefix`, new in this version, to get the lines as the container wrote them.
>
> **A container of a service's name that opossum did not make is no longer taken for the service.** A container made outside opossum, such as with `container run --name web.myapp.opossum`, carries no `opossum.project` label: `up` and `run` now refuse it and exit 1, where `up` used to reuse it, and `down` leaves it, where it used to delete it. Remove it (`container delete --force <name>`) to let `up` make the service's own. Containers opossum made carry the label and are not affected.
