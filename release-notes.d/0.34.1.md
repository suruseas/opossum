> [!WARNING]
> **A `ports` protocol written in upper case is now read in lower case, which changes two things on the first `up`.**
>
> A service whose short-form `ports` entry writes the protocol in upper case (`"8080:80/TCP"`) is recreated on the first `up` after upgrading, once. And a file that publishes one port twice — a long-form entry with `protocol: TCP` beside a short-form `"8080:80/TCP"` — no longer starts: the short form now settles as `/tcp` while the long form keeps `TCP`, so they are two entries on one host port, and the runtime refuses the pair (`host ports for different publish port specs may not overlap`). docker compose does the same with that file. Keep one of the two entries.
